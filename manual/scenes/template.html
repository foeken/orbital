Tasks move from Inbox to done

A task is a node with a state. You set it with one key, hand it to someone with another, and Orbital keeps the rest in step with Tana.

    The four states

    Every task is in one of four states: Inbox, In Progress, Completed and Later.

    Tick it off ⌘↩

    With the caret in a task, ⌘↩ completes it: the box squashes, the tick draws, the title is struck.

    1. Checkbox ticks the task in Tana.
    2. Grey line says who has it and who can see it.
    ⌘K→ type status →↩ and pick Later.
    A done task stays where it is until you press Clean up, so nothing moves under you while you work.
